Hotel Review Rating Prediction Using Deep Learning

A deep learning project that predicts hotel review ratings from textual reviews using Word2Vec embeddings, and a Bidirectional LSTM neural network.

Key Results
Dataset: 20,491 hotel reviews
5-class rating prediction
Word2Vec word embeddings
Bidirectional LSTM architecture
Accuracy: 62.35%
Macro F1-score: 53.80%

Technologies

Python · TensorFlow · Keras ·  Scikit-learn ·  Deep Learning

Pipeline

Raw Reviews → Text Preprocessing → LDA Topic Modeling → Word2Vec → BiLSTM → Rating Prediction
